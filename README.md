# Coffee Shop Sales Analysis Dashboard

## 📊 Project Overview
This project presents an interactive Coffee Shop Sales Analysis
Dashboard developed using Microsoft Excel.
The dashboard analyzes coffee shop sales and transaction data to
identify sales trends, customer transaction patterns, product
performance, and store-level performance.

## 🎯 Project Objectives
- Analyze monthly sales trends
- Analyze transactions by hour of the day
- Analyze transactions by day of the week
- Identify popular product categories
- Analyze product-wise sales performance
- Compare performance across store locations
- Provide interactive filtering for business analysis

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Slicers
- Data Cleaning
- Data Analysis
- Dashboard Design

## 📈 Dashboard Visualizations
The dashboard contains:
1. Sales by Month
2. Category-wise Number of Transactions
3. Number of Transactions by Hour of the Day
4. Number of Transactions by Day
5. Product Type-wise Transaction Count
6. Product Type-wise Sales

## 🎛️ Interactive Filters
The dashboard includes filters for:
- Store Location
- Transaction Date

The store locations available in the dashboard include:
- Astoria
- Hell's Kitchen
- Lower Manhattan

## 📌 Key Metrics
The analysis includes:
- Total Transactions
- Total Sales
- Monthly Sales
- Product-wise Sales
- Category-wise Transactions
- Hourly Transaction Trends
- Daily Transaction Trends

## 💡 Key Insights
The dashboard can be used to identify:
- Monthly sales trends
- Peak transaction hours
- Most active days of the week
- Best-performing product categories
- Products generating higher sales
- Differences in performance between store locations
